# HM-SYSTEM

Full Stack Application — React + FastAPI + SQL Server

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS v3 + Redux Toolkit + React Router + Axios + TanStack Query
- **Backend:** Python + FastAPI + pyodbc + Uvicorn
- **Database:** Microsoft SQL Server (pyodbc)

## Quick Start

### Frontend
```
cd frontend
npm install
npm run dev
```

### Backend
```
cd backend
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Database
Update `backend/.env` with your connection string.
